# ☕ Java Öğreniyorum

Sıfırdan Java öğrenme yolculuğumda yazdığım örnekleri, alıştırmaları ve küçük projeleri bu depoda topluyorum. Her klasör ayrı bir IntelliJ IDEA projesidir ve tek bir konuya odaklanır.

## 📚 İçindekiler

### Temeller

| Klasör | Konu |
|---|---|
| `Operatorler` | Aritmetik, karşılaştırma ve mantıksal operatörler |
| `tur-donusumu` | Veri tipleri arasında tür dönüşümü (casting) |
| `kullanicidan-deger-alma` | `Scanner` ile kullanıcıdan veri okuma |
| `kosul-yapilari` | `if`, `else if`, `else` ve `switch` |
| `Donguler` | `for`, `while`, `do-while` döngüleri |
| `Diziler` | Dizi tanımlama ve dizilerle çalışma |
| `methods` | Metot yazma, parametre ve dönüş değeri |
| `breakpoint` | Hata ayıklama (debug) ve breakpoint kullanımı |

### Mini Uygulamalar

| Klasör | Açıklama |
|---|---|
| `login` | Basit kullanıcı giriş kontrolü |
| `atm-ornegi` | Konsol tabanlı ATM simülasyonu |
| `dizideki-asallari-bul` | Bir dizideki asal sayıları bulan program |

### Nesne Yönelimli Programlama (`javada oop/`)

| Klasör | Konu |
|---|---|
| `oop-giris` | Sınıf, nesne ve paket kavramlarına giriş (`Ogrenci`) |
| `kapsulleme` | Kapsülleme (encapsulation), `private` alanlar, getter/setter (`Calisan`) |
| `inheritence` | Kalıtım (inheritance), `Kopek` ve `Kedi` sınıflarıyla `hayvan` paketi |
| `alistirma-calisanlar` | Çalışan sınıfı ile alıştırma |
| `giseUygulamasi-alistirma` | Gişe uygulaması alıştırması (`TCKNN`) |

## 🚀 Nasıl Çalıştırılır?

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/yasinCulha/java-ogreniyorum.git
   ```
2. İlgili klasörü **IntelliJ IDEA** ile proje olarak açın.
3. `src/Main.java` dosyasını çalıştırın.

> Gereksinim: JDK 8 veya üzeri.

## 🎯 Amaç

Konuları yalnızca okumak yerine kod yazarak pekiştirmek ve öğrendikçe bu depoyu yeni örneklerle büyütmek.
